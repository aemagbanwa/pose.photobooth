# POSE Partners v1.9 — Enterprise email templates

## Updated transactional emails
- Partner registration → admin application review email
- One-time login verification code (10-minute validity retained)
- Partner account approval
- Affiliate new referred inquiry
- Affiliate confirmed booking
- Affiliate withdrawal request → admin
- Affiliate payout marked paid → partner (new)

All now use consistent responsive, table-based HTML with inline styles, a POSE Partners header, status kicker, event detail tables, prominent action buttons, secure/plain-text fallbacks, and neutral footer. Dynamic values are escaped before entering HTML. Existing inquiry backend administrator/customer HTML emails are already branded, and are preserved. No client contact information is added to affiliate emails. The backend does not attach a screenshot; the affiliate sees it in the authenticated dashboard.

## Deployment
Replace `backend/pose-partners.gs` in the **POSE Partners** Apps Script project (not the inquiry script), save, run `sendPartnerEnterpriseTestEmails()` from the editor to email 3 previews to the configured `PARTNERS_ADMIN_EMAIL`, verify Gmail rendering, then Deploy → Manage deployments → Edit → New version → Deploy. Apps Script may request MailApp permission if not previously granted.

No spreadsheet migration is required. Website HTML/CSS/JS from v1.8 is unchanged. Live email sending has not been tested in this environment.
