# POSE Partners v1.8 — Enterprise Interface

This release redesigns **all five POSE Partners screens**: `/partners/`, `/partners/register.html`, `/partners/dashboard.html`, `/partners/admin.html`, and `/partners/terms.html`.

## What changed
- Unified enterprise visual system: structured page headers, consistent navigation, refined typography, restrained POSE magenta accents, neutral cards, responsive grids, tables, forms and dialogs.
- Marketing landing page: editorial hero, prominent register/login actions, clearer three-step referral journey, and retained service commission and tier tables.
- Registration: clearer input grouping and dedicated wallet / QR section.
- Partner dashboard: KPI cards and in-page navigation to referral link, wallet/payouts, notifications, inquiries and commission history.
- Admin dashboard: in-page navigation for applications, inquiry review, reconciliation, booking commissions and payouts.
- Terms: improved readability of the existing policy text.

## Compatibility and deployment
- Only `/partners/*.html` and `/assets/css/partners.css` were changed; existing backend, routes, JavaScript handlers, form names and element IDs are preserved.
- Upload the website files to your existing hosting. **No Apps Script redeployment is required for this visual-only update.**
- No real backend interactions were tested in a deployed environment. Test login, registration, referrals, dashboard and payout operations against your own deployment before production release.
- Font falls back to system fonts if Google Fonts is blocked.
