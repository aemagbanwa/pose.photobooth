# POSE Website V2.4 — Inquiry Form Cleanup

- Interested In is a service **category**; Package is a dependent dropdown with relevant choices only.
- Package choices are disabled until the customer picks a category.
- `Not sure yet` automatically chooses `Help Me Choose`, allowing an inquiry without a specific package.
- Existing homepage buttons and the package finder populate both fields using the original backend-compatible package IDs.
- The projector presentation remains an optional add-on, not a primary package.
- Inquiry package definitions, categories, customer labels and estimate prices are now centralized in `assets/js/app.js` as `POSE_PACKAGES`.
- Quotation totals continue to update on selection, including programmatic selections and form resets.
- No live deployment or Google Apps Script changes performed. Please browser-test the form, inquiry delivery and pricing before publishing.

**Pricing caveat:** Existing standalone package rates were carried forward from V2.3; confirm them against the current rate card before publication. Bundle packages are proposed marketing rates.
