# POSE v2.1 — Official Logo Contrast Fix (All Email Templates)

## Issue resolved
The official transparent POSE logo uses magenta **POSE** and black **Photobooth** lettering. Previous enterprise email layouts placed this logo on a near-black header (`#17151a`), so **Photobooth** disappeared. The logo image itself has not been recolored, boxed, replaced or altered.

## Changes
- **POSE Inquiry Backend:** Both admin inquiry and customer confirmation templates now use a clean white header with dark headlines, legible secondary text and a POSE-magenta bottom rule.
- **POSE Partners Backend:** Shared email header is now white with dark “PARTNERS PROGRAM” label and POSE-magenta bottom rule. This applies to registration, approval, login code, referral, booking, payout and other emails sent through the shared enterprise mail helper.
- The official transparent file `assets/images/POSE_Light_Transparent.png` is unchanged.

## Deploy
1. Update **POSE Inquiry Backend** Apps Script using `backend/pose inquiry.gs`. Save, authorize required permissions, run `sendPoseEnterpriseInquiryTestEmails()`, then redeploy the existing Web App as **New version**.
2. Update **pose-partners** Apps Script using `backend/pose-partners.gs`. Save, run `sendPartnerEnterpriseTestEmails()`, then redeploy as **New version**.
3. Keep current Script Properties; do not reset database IDs, sync endpoint or secret. `POSE_EMAIL_LOGO_FILE_ID`, when set, must point to the actual official transparent logo.
4. Verify emails in Gmail on desktop and mobile. Confirm the black Photobooth lettering is visible.

**Testing:** Static source checks only; live Apps Script authorization, email delivery and Gmail rendering must be verified after deployment.
