# POSE Website v2.1 — gallery, comparison & conversion instrumentation

Built on the v2 archive; retains the existing directory tree and Google Apps Script inquiry integration.

## Changes
- Made homepage event gallery category filters functional and keyboard accessible, using existing site media rather than fabricated event images. Added a Trading Card service preview.
- Added responsive, horizontally scrollable comparison table for Classic Photobooth, Photoman, 360 Video Booth and Trading Card Photobooth.
- Added privacy-minimal conversion event hooks: `pose_package_inquiry_click`, `pose_gallery_filter`, `pose_messenger_click`, `pose_inquiry_posted`. These dispatch `pose:analytics` events and push onto `window.dataLayer` only when a dataLayer already exists. No GA4/Meta Pixel tracking ID, external script, or personal contact data is inserted.
- Improved form submission notice because opaque cross-origin requests cannot confirm receipt.

## Before publication
1. Preview on a staging URL and check gallery filters, mobile comparison table and inquiry buttons.
2. Verify the Google Apps Script endpoint and actual delivery; fallback `no-cors` requests cannot verify server acceptance and could duplicate submissions if first attempt succeeded but CORS failed.
3. To activate analytics, provide the actual GA4 or Meta Pixel account ID, establish appropriate notice/consent, and attach a listener / tag manager; event hooks alone do not send data externally.
4. Review which event images are authorized for public use; current existing images are retained, not independently verified.
5. Confirm all prices and projector/printing inclusions prior to advertising.

Deployment: back up the site, then replace its files with the ZIP contents, preserving directory hierarchy. Live site is unchanged.
