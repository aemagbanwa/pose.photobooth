# POSE Website V2.3 — Review Before Inquiry Submission

## Added
- Review step for the existing interactive quotation builder.
- Shows client name, contact, email (if supplied), event date, type, venue, service, package, add-ons, extra hours, and estimated total.
- Clear statement that the amount is indicative, excludes unquoted extras, and is **not** a confirmed quotation or reservation.
- **Edit details** and **Confirm & Send Inquiry** actions.
- No customer information is sent by opening the review dialog. The original inquiry flow runs only after confirmation.
- Accessible native HTML dialog, keyboard support and responsive layout.
- Does not alter the Apps Script payload or prices.

## Deployment notes
- Deploy the entire ZIP to your staging site, not directly to production before testing.
- For the V2.2 estimate fields, the Apps Script still requires the redeployment described in V2.2-UPDATE-NOTES.md.
- Confirm receipt in the Google Sheet and notification emails using a real test inquiry.
