# POSE Photo Wall gallery

This update changes the public event gallery to a warm-white photo wall with magenta accents, staggered album covers, titles beneath the images, and visible search and filter controls on mobile.

## Install

Replace these three files in your existing website, keeping their paths:

- gallery/index.html
- gallery/styles.css
- gallery/app.js

The archive also includes the complete original project. Your existing backend, configuration, shared header/footer, admin pages, PIN controls, sharing, downloads and pagination are retained. No backend redeployment is needed. The HTML updates asset version parameters to refresh cached CSS and JavaScript.

Landscape album covers use varied crops for the wall; portrait photos and strips retain their full proportions. Opening an album still uses the existing full-image viewer.

## Verification

JavaScript syntax, HTML hooks and unchanged project files were checked. Browser visual and interaction checks could not run because the browser download was unavailable in this environment.
