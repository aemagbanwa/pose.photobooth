# POSE Website V2.2 — Quote Builder

## Included
- Interactive quote builder embedded in the existing inquiry form.
- Base price, eligible add-ons, extension quantities and indicative total.
- Disabled incompatible add-ons and prevented duplicate projector/guestbook upsells.
- Preserved all V2.1 pages, assets and previous functionality.
- Updated Apps Script inquiry handler to save Requested Add-ons, Estimated Total and Extra Hours to Google Sheets, and include them in owner/customer emails.

## IMPORTANT DEPLOYMENT STEP
The backend file `backend/pose inquiry.gs` is **not deployed automatically**. Update and redeploy your Google Apps Script web app to receive the new add-on and estimate fields. Existing published endpoint may accept submissions but ignore those fields until redeployed. Check script deployment URL and update `assets/js/inquiry-config.js` if it changes. Do not overwrite existing script properties.

## Estimate rules
- Prices are indicative; no online payment or booking confirmation.
- Transportation and venue-related fees excluded.
- Only published numeric add-ons are computed. Video Guestbook on a non-included package is a request, not a numerical charge.
- Extra hours are priced only where a public extension rate is known; other requests require a custom quote.
- Package names/prices reflect the previous V2.1 website, not a new pricing approval. Verify published rates before go-live.

## Verify before live
1. Test each package in desktop and mobile browser.
2. Confirm valid combinations, pricing and subtotal.
3. Redeploy Apps Script and submit a test inquiry.
4. Verify add-ons, estimate and additional hours appear in the Google Sheet and emails.
5. Test Facebook contact and every relevant link.
