# POSE v2.0 – Unified Enterprise Email Branding

This version fixes the gap in v1.9: **both** the POSE Partners backend **and** the separate POSE Inquiry Backend email templates are updated.

## Official logo

All outgoing partner and inquiry emails use the existing official transparent POSE wordmark from `assets/images/POSE_Light_Transparent.png`, without a background, border or substitute text wordmark. Both scripts try to embed the same official logo as an inline image when `POSE_EMAIL_LOGO_FILE_ID` is configured; otherwise they reference `https://poseph.com/assets/images/POSE_Light_Transparent.png` (ensure that exact file is publicly hosted at that path). Embedding is recommended for consistent rendering across email clients.

1. Upload `assets/images/POSE_Light_Transparent.png` to **your private Google Drive** (do not make the Drive file public).
2. Copy its Google Drive file ID.
3. In **both** Apps Script projects, set script property `POSE_EMAIL_LOGO_FILE_ID` to that file ID. The deploying account must have Drive access. If your `appsscript.json` declares explicit `oauthScopes`, include `https://www.googleapis.com/auth/drive.readonly` alongside all the existing required scopes. Do **not** remove the existing external_request or spreadsheet scopes. Approve permissions when prompted.
4. If you do not configure the Drive file ID, upload the included official transparent image to your website at `/assets/images/POSE_Light_Transparent.png` and verify the public URL. Some email clients may block remote images by default.

## Deploy BOTH independent backends

**A. Inquiry backend**: Replace code in the separate *POSE Inquiry Backend* Apps Script project with `backend/pose inquiry.gs`. Save and run `sendPoseEnterpriseInquiryTestEmails()` to send the admin inquiry email and customer confirmation to your configured notification address. Grant additional Drive permission if needed, then **Deploy > Manage deployments > Edit > New version**. Confirm website inquiries still submit and that affiliate synchronization remains intact. You must redeploy the Inquiry backend or the live inquiry emails will continue to use its old templates.

**B. Partners backend**: Replace code in *pose-partners* with `backend/pose-partners.gs`. Save and run `sendPartnerEnterpriseTestEmails()`. Redeploy the existing Partners web app (new version). Do not replace its existing Script Properties, database, or shared secret.

**C. Website asset**: Publish `assets/images/POSE_Light_Transparent.png` to the expected path if using fallback. No other website changes are required for the email templates.

## Templates covered

- POSE Inquiry: new customer inquiry to POSE, confirmation to customer.
- POSE Partners: affiliate application notification, approval, OTP, referred inquiry, confirmed booking, withdrawal request and payout confirmation.

## Testing limitations

Syntax can be checked offline, but actual Gmail/Apps Script rendering, permissions, and deployed versions must be verified in your Google account. The new email templates do not modify commission rules, referral tracking, or Google Sheets.
